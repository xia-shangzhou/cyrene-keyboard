## ⚠️ 风险提示（动手前请先读完）

**这是个人自制的第三方工具，不是官方软件**，与米哈游、键盘厂商都没有关系。
它通过逆向出来的厂商协议直接给键盘发灯效参数 —— 协议没有官方文档背书，
所以下面这些得你自己掂量：

- **可能影响键盘寿命。** 长时间最高亮度、极限速度、音乐律动连续推流，都属于超出
  日常使用的负载。灯珠和控制芯片不是按这个强度设计的，**长期这么玩有加快老化的可能**。
- **出问题自己承担。** 任何因使用本程序导致的硬件异常、灯效错乱、按键失灵、键盘损坏
  或其他直接间接后果，**都由使用者自行负责**，作者不提供担保，也不负责赔偿或维修。
- **已知的安全边界**（这些代码里是硬拦截的）：不刷固件、不改键、不写宏、不动配对，
  固件升级与 bootloader 命令一律拒绝发送。
- **想保守一点**：别长时间开最高亮度；律动别一整天挂着；觉得不对劲就停掉程序，
  用键盘自己的 Fn 组合键把灯效恢复出厂设置。

> **不放心就别用。** 用它就等于你接受「这是非官方工具、可能有未知风险」这个前提。

## 🎵 音乐律动

整个软件最有意思的功能：**抓系统正在播放的声音，实时变成键盘上的音柱。**

用 WASAPI 回环采集（不需要开「立体声混音」、不独占设备、不影响你听歌），
做完 FFT 分成 8 个频段，再推给键盘渲染。

![音乐律动](docs/live_律动.png)

**实际用起来需要知道的：**

- **只有 8 列，不是 16 根细柱** —— 这是键盘固件决定的渲染方式，软件改不了
- **横向样式选「从左向右」只亮左侧一小段** —— 竖向柱和「从中间向两边」都正常，建议用这两种
- **颜色是固件内置的彩虹循环**，本协议下无法自定义
- **延迟约 130ms**，听歌够用，卡点视频对不上
- **自带自动增益**：扬声器和蓝牙耳机的回环电平能差 16 倍，程序会自己跟着调
- 采集源可选，选错了会提示（比如选成虚拟声卡，抓到的是别的程序灌进去的声音）

> 💡 **打游戏、录视频时**：建议插 USB 线，有线能跑满 50Hz，灯跟得更紧。
> 蓝牙下默认 25Hz、也可以手动切 50Hz，带宽窄一点，但只听歌看灯完全够用。

## 📥 下载安装

> 下载之前**先读一遍上面的风险提示**：个人自制工具，可能影响键盘寿命，用出问题后果自负。

到 **[Releases](../../releases/latest)** 页面，两个包**任选一个**，都是免安装、解压即用。

| 包 | 体积 | 怎么启动 | 说明 |
|---|---|---|---|
| `CyreneKeyboard-Portable-v*.zip` | ~105 MB | 解压 → 双击 `启动.bat`（`使用说明.txt` 就在旁边） | **推荐先试这个**：不产生未签名的可执行文件，通常不会触发针对未签名程序的策略 |
| `CyreneKeyboard-v*-win64.zip` | ~60 MB | 解压 → 进 `CyreneKeyboard` 文件夹，双击 `CyreneKeyboard.exe` | exe 版，体积小一半；但**智能应用控制（SAC）处于强制模式的机器会被拦**（已实测） |

### 为什么推荐便携版（先看这段，能少踩坑）

程序没有买代码签名证书（个人项目，一年几千块）。Windows 11 的**智能应用控制（SAC）**
一旦处于「强制」模式，就只放行**有签名、或者已经有信誉**的程序：

- 每个新版本的 exe 都是**全新文件**，没有信誉积累 → **必然被拦**
- 拦下来的提示是「应用程序控制策略已阻止此文件」，**没有「仍要运行」可以点**
- 这不是误报，也不是包坏了；只有整个关掉 SAC 才能用，而 SAC 关掉以后基本不可逆，不建议

便携版的做法不同：它由 **Python 官方签名的 `pythonw.exe`** 来执行 `.py` 脚本，
整个运行过程不产生新的、未签名的可执行文件，因此不触发「针对未签名二进制」的策略。
这不是绕过安全检查 —— 执行主体是系统本来就信任的解释器，本程序只是它的输入。

这一点需要说清楚：**Python 解释器有数字签名，不等于本程序已签名。**
本程序自己的代码没有签名，只是它不以 PE 文件的形式运行。
**不能保证在所有安全设置下都放行** —— 如果便携版也被拦，请按下面的“遇到拦截”一节收集信息反馈。

### exe 版被拦了怎么办

| 你看到的 | 该怎么办 |
|---|---|
| 「Windows 已保护你的电脑 / 未知发布者」 | 点 **更多信息 → 仍要运行**，之后就正常了 |
| Windows 11 提示「智能应用控制已阻止」 | **没有绕过办法**（点不了“仍要运行”），直接改用 Portable 包 |
| exe 双击没反应、被杀软直接删掉 | 改用 Portable 包 |

**所以：exe 版被拦、被删、打不开，就直接下 `CyreneKeyboard-Portable-v*.zip`**，
功能完全一样、体积大一倍。它不产生未签名的二进制，通常不会触发上面那些策略，
但**不同机器的安全设置不同，不能保证在所有环境下都放行**。

两个包的共同点：

- **免安装**：不写注册表、不改系统设置，删掉文件夹就是卸载
- **不用装 Python，也不用装 VC++ 运行库**：包里自带 Python 3.13.12 运行时 + 全部依赖
  （PySide6 / numpy / soundcard）+ `vcruntime140` / `msvcp140`，换台新电脑解压就能用
- **系统要求：Windows 10 / 11，64 位**（Qt 6 不支持 Win7 / Win8，也不支持 32 位系统）
- **首次启动默认只读模式**，要调灯效点右上角解锁
- **双击 `启动.bat` 后窗口闪一下就消失是正常的**：程序已经起来了，只是不留命令行窗口
- 万一双击没反应：在文件夹里按住 <kbd>Shift</kbd> 右键 →「在此处打开 PowerShell 窗口」，输入
  `.\python\python.exe main.py` 回车，报错会直接显示出来

## 🔌 三种连接

| 连接 | 调灯效 | 音乐律动 | 建议 |
|---|---|---|---|
| **USB 有线** | ✅ | ✅ 50Hz | 调灯、玩律动就用它 |
| **蓝牙** | ✅ | ✅ 默认 25Hz | 日常无线，也能调灯 |
| **2.4G 无线** | ❌ | ❌ | 只适合打字 |

蓝牙和有线都能调灯，**2.4G 接收器不行** —— 它只转发按键，不转发灯效指令。
这是接收器固件的设计，不是软件的问题。想调灯就插线，或者切到蓝牙。

## ❓ 常见问题

**Q：exe 版和 Portable 版有什么区别？该下哪个？**
功能一模一样，只是打包方式不同。exe 版体积小一半、启动快，但没有代码签名，
Windows 可能弹「未知发布者」（点更多信息 → 仍要运行），也可能被智能应用控制或杀软直接拦掉。
**被拦了就换 Portable 版** —— 它借 Python 官方带签名的解释器当启动器，绕开了这道门，
代价是体积大一倍。删了都干净，不写注册表。

**Q：2.4G 下为什么调不了灯？**
接收器只做按键透传，这是它固件决定的，各种办法都试过，不通。

**Q：能看电量吗？**
按键盘 `Fn + Backspace`，数字键 1-0 亮起几颗就是几十%。软件里不显示电量 ——
三种连接里两种给不出准确读数，摆个数字反而误导。

**Q：自定义灯光怎么录？**
`Fn + Z`（或 `X` / `C`）进入模式 → 按 `Fn + V` 开始录制（**Fn 键亮红灯闪**）→
逐个按要亮的键 → 再按 `Fn + V` 保存（红灯停止闪）。软件「逐键」页里有完整图文。

**Q：会不会动我的键盘固件？**
不会。只发灯效参数，不刷固件、不改键、不写宏、不动配对。
固件升级、改键、宏、bootloader 这些命令在代码里是**硬拦截**的。
